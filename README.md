# Tacktile2048 🧩2️⃣0️⃣4️⃣8️⃣

Tacktile2048 is a puzzle game that challenges players to combine numbers to reach the number 2048 or higher. Players can slide tiles up, down, left, and right to combine matching numbers.
The app supports multiple grid sizes, making the game more varied and challenging.

---

## ✨ Features

- Simple and clean design
- Smooth gameplay experience
- Score calculation and best score saving
- Challenging and relaxing gameplay
- Easy to play, hard to master
